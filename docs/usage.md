# Uso

- **Missões** reúne as missões da sala. O mestre usa **Nova missão** para escolher os jogadores e publicar. Na própria lista, pode editar o título, concluir ou apagar uma missão publicada. O olho indica a leitura, e o título de uma missão concluída aparece riscado.
- Uma missão começa **Disponível**. Na primeira leitura, ela passa para **Em andamento**. No progresso compartilhado, a primeira leitura vale para todos. No individual, cada jogador começa ao ler. Quando o mestre conclui a missão, ela fica **Concluída** para todos.
- **Histórico** mostra a atividade mais recente de cada missão que você pode acessar.
- **Configurações** oferece nome de personagem e desativação de animações neste navegador. O mestre também encontra ali o tema da campanha.
- **Painel do mestre** oferece o código para convidar jogadores. Em **Participantes**, o mestre pode atualizar personagens e suspender ou reativar acessos.
